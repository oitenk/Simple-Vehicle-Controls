# Simple Vehicle Controls

One key each for the engine, doors, windows, hood and trunk of the car you are in, or the one you are looking at. Built it with Claude (the AI).

| Key | Does |
|---|---|
| Numpad 2 | Engine on / off |
| Numpad 8 | Hood open / close |
| Numpad 5 | Trunk open / close |
| Numpad 4 | Left door open / close |
| Numpad 6 | Right door open / close |
| Numpad 7 | Left window up / down |
| Numpad 9 | Right window up / down |

All six keys can be changed in Mod Settings.

The game does not report where a window is, so the mod remembers the windows it moved. That memory lasts until you quit the game.

## Requirements

- [redscript](https://github.com/jac3km4/redscript)
- [Codeware](https://github.com/psiberx/cp2077-codeware)
- [Mod Settings](https://www.nexusmods.com/cyberpunk2077/mods/4885) (optional, for changing the keys)

## Install

Install the zip with Vortex, or extract it into the game folder.
